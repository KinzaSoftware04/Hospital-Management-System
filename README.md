# 🏥 Hospital Management System

✨ **Welcome to the Hospital Management System!** This repository contains a console-based backend database application engineered using Python to handle real-world clinical records dynamically.

The script focuses on structural code design, persistent storage architectures, and automated system flows.

---

## 🦄 Features & Functions

* 📝 **Patient Registration:** Captures clinical data records and structures patient info smoothly.
* 💾 **Persistent Text Database:** Employs native Python **File Handling** (`with open` in append mode) to log records permanently into a local file.
* 📁 **Data Structure Mapping:** Uses nested dictionary frameworks to organize patient profiles cleanly before physical storage deployment.
* 🔄 **Control Flow Automation:** Structured with controlled operational menu loops and invalid choice validation mechanisms.

---

## 🛠️ Built With

* 🐍 **Python 3.x** — Multi-branch data logic and operational script control.
* 📁 **File I/O Infrastructure** — Local text-file data storage logging.
